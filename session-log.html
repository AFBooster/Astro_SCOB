Everything here is stored only in this browser (localStorage) — nothing is uploaded anywhere. Use Export CSV to back it up or open it in a spreadsheet for planning and Science Centre reporting. The only network call is an optional weather-forecast lookup (fixed observatory coordinates, no personal data) so the go/no-go call can be graded against the night that actually happened — the 🔮 Forecast accuracy button. The Pull from Now Showing board button reads whatever the Now Showing display currently has, so you can log a night with one tap. Clearing your browser data will erase the log, so export periodically.
