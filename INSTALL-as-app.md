# Install SCOB Night-Sky as a phone app

The site is a **Progressive Web App**: it can sit on your home screen with its own
gold-moon icon, open full-screen like a normal app, and keep working in the dome with
no signal (everything astronomical is computed on the phone).

## Install it

Open **https://afbooster.online** on the phone, then:

- **iPhone / iPad (Safari):** tap **Share** → **Add to Home Screen** → **Add**.
- **iPhone / iPad (Chrome):** tap **Share** (in the address bar) → **Add to Home Screen**.
- **Android (Chrome):** tap **⋮** → **Install app** (or **Add to Home screen**) → **Install**.

The dashboard picks the phone or desktop layout automatically; the **Auto / Desktop /
Mobile** switch at the bottom right overrides it.

## Updates

Nothing to do. When a new version is published, the app fetches it in the background
and shows **"🔄 New version available — tap to refresh"**. Tap it, or simply close and
reopen the app.

If a phone ever seems stuck on an old version, open the site in the browser itself
(not the home-screen icon) and reload, or remove the icon and add it again.

## What needs a signal

Only the live feeds: the weather forecast and rain radar, NEA's haze readings and the
air-quality forecast, satellite orbits for pass predictions, solar activity, and the
satellite images on the Haze page. The sky map, Moon, planets, targets, comets and
events all work offline once the app has been opened once.
